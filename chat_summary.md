### Claude.ai Planning Sessions

In addition to Claude Code, the project used Claude.ai (browser chat) for assignment
planning, prompt engineering, and iterative site critique. Key contributions:

- Clarified the brms 2PL specification (Bürkner 2021 formulation, 1 chain 500 samples
  as per course instructions)
- Designed the initial Claude Code prompt structure and subsequent improvement prompts
  across multiple passes
- Reviewed site output iteratively and identified substantive issues: Die Linke
  government–opposition anomaly, posterior sign contradictions, party ordering,
  missing bridging text and conclusion
- Discussed methodological questions including convergence warnings, sampling
  specifications, and horseshoe prior interpretation
- Generated all Claude Code prompts used in this project

**Prompt engineering approach:** Prompts were designed to be explicit and sequential,
with each Claude Code session reading existing files before making changes and confirming
each step before proceeding. Iterative critique cycles between Claude.ai and Claude Code
were used to improve both analytical content and site design across approximately 8 prompt
passes.
